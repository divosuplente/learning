## What You'll Learn

- Authentication vs authorization
- `SecurityFilterChain` configuration (replacing `WebSecurityConfigurerAdapter`)
- Form login, HTTP Basic, and `UserDetailsService`
- `BCryptPasswordEncoder` and password storage
- URL-based authorization with `authorizeHttpRequests`
- Method-level security with `@PreAuthorize` and SpEL expressions
- JWT structure and stateless authentication
- OAuth2 Resource Server and OAuth2 Client configuration
- CSRF protection and CORS configuration

## Prerequisites

- Module 03 (Spring Boot Fundamentals) completed
- Understanding of REST controllers and request/response lifecycle
