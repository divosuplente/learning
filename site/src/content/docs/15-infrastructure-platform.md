## What You'll Learn

- Kubernetes fundamentals: Pods, Deployments, Services, ConfigMaps, Secrets
- Deploying Spring Boot apps from jar to running cluster
- Infrastructure as Code with Terraform: providers, resources, state, modules
- Managing multi-environment K8s configs with Kustomize overlays
- GitOps principles and continuous delivery with Argo CD
- Sync policies, health status, and cluster drift detection

## Prerequisites

- Modules 00-14 completed
- Basic understanding of Docker and containers
- Familiarity with Git workflows
