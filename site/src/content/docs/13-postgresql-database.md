## What You'll Learn

- PostgreSQL-specific types: UUID, JSONB, ARRAY, ENUM, SERIAL
- Connecting Spring Boot to PostgreSQL and mapping types with JPA
- Hypersistence Utils for JSONB and ARRAY support
- Index types: B-tree, Hash, unique, composite, partial, covering
- Finding missing indexes with `EXPLAIN ANALYZE`
- How the query planner chooses execution strategies
- Common planner mistakes and how to fix them

## Prerequisites

- Module 04 (Repository Pattern) completed
- Understanding of JPA entities and Spring Data repositories
