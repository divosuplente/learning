A full-stack backend curriculum — from Java syntax to production deployment. Every module builds on the last, ending with a capstone project that ties everything together.

## Core Language & Tools

1. [Java Foundations](lessons/00-java-foundations/0001-java-records/) — Records, generics, pattern matching, sealed classes, collections, OOP
2. [Build Tools](lessons/01-build-tools/0010-build-tools-and-maven-basics/) — Maven, Gradle, Spring Initializr, project structure
3. [Dependency Injection](lessons/02-dependency-injection/0015-tight-coupling-and-di/) — Spring IoC, bean lifecycle, scopes, qualifiers
4. [Spring Boot Fundamentals](lessons/03-spring-boot-fundamentals/0020-auto-configuration/) — Auto-configuration, REST controllers, validation

## Data & Architecture

5. [Repository Pattern](lessons/04-repository-pattern/0025-databases-and-repository-pattern/) — JPA, Spring Data, custom queries, N+1
6. [Service Oriented Architecture](lessons/05-service-oriented-architecture/0030-architecture-patterns/) — Layered architecture, DTOs, events
7. [Kafka](lessons/06-kafka/0035-sync-vs-async/) — Async messaging, producers, consumers, DLQ
8. [GraphQL](lessons/07-graphql/0040-rest-problems-over-under-fetching/) — Schema-first design, resolvers, DataLoader

## Advanced

9. [Reactor Pattern](lessons/08-reactor-pattern/0045-reactive-programming-paradigm/) — Reactive Streams, Mono/Flux, WebFlux, virtual threads
10. [TDD](lessons/09-tdd/0050-what-testing-is/) — JUnit 5, Mockito, Spring Boot Test, Testcontainers
11. [Capstone Project](lessons/10-capstone-project/0055-capstone-architecture/) — Full-stack order management system
12. [Migrating Java to Kotlin](lessons/11-migrating-java-to-kotlin/0058-why-kotlin/) — Data classes, coroutines, null safety

## Data Access & Security

13. [R2DBC & Reactive Data Access](lessons/12-r2dbc-reactive-data/0063-r2dbc-introduction/) — Non-blocking DB access, Spring Data R2DBC
14. [PostgreSQL & Advanced Database Concepts](lessons/13-postgresql-database/0066-postgresql-deep-dive/) — Indexes, query planner, EXPLAIN ANALYZE
15. [Spring Security](lessons/14-spring-security/0069-spring-security-authentication/) — Auth, JWT, OAuth2, CSRF, CORS
16. [Infrastructure & Platform Engineering](lessons/15-infrastructure-platform/0073-kubernetes-fundamentals/) — Kubernetes, Terraform, Argo CD
