## What You'll Learn

- Docker fundamentals: images, containers, Dockerfile basics, building and running
- Multi-stage builds for Java/Spring Boot: layer caching, image optimization, slim production images
- Docker Compose for local development: service orchestration, networking, and multi-service stacks

## Prerequisites

- Modules 00-14 completed
- Java 21 and Maven installed
- Docker Desktop (or Docker Engine) installed and running
