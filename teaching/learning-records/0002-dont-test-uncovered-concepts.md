# Don't Test on Uncovered Concepts

Quiz questions must only test material introduced earlier in the same lesson. The
learner flagged surprise at a null-handling question because null behavior
wasn't explained. Added a compact constructor section before the quiz to
remediate.

**Rule for future lessons:** If a quiz tests X, X must be taught in the lesson
first. No gotchas, no "do you know this thing I haven't mentioned yet?"
